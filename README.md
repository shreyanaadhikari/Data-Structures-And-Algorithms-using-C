# Data-Structures-And-Algorithms
# 📊 DSA Files

A collection of Data Structures and Algorithms programs implemented during my BSc. CSIT coursework at St. Xavier's College, Kathmandu.

## 📚 Topics Covered
- Arrays, Stacks & Queues
- Linked Lists (Singly, Doubly, Circular)
- Trees (BST, AVL Trees)
- Graphs (BFS, DFS, MST — Kruskal's & Prim's)
- Sorting Algorithms (Bubble, Quick, Merge, Insertion)
- Searching Algorithms (Linear, Binary)
- Hashing Techniques

## 🛠️ Tools & Languages
- C programming
- VS Code, Dev C++
